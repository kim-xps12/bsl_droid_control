# biped_msgs

`biped_msgs` は BSL-Droid 歩行系の将来拡張に備えたカスタムメッセージ定義パッケージです。

## 定義されているメッセージ

| メッセージ | 用途 |
|---|---|
| `SafetyStatus.msg` | 安全監視ノードの集約状態通知 |
| `RLPolicyState.msg` | RL 推論ノードの観測・行動・推論時間のデバッグ出力 |

## 現在の実装状態

- メッセージ生成自体は有効です。
- 2026-03-10 時点では、`ros2_ws` 内の実装済みノードでこれらを publish しているものはありません。
- したがって本パッケージは「将来使うための型定義」が主な役割です。
